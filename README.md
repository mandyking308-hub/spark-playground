# Spark Playground

Give Lovable one very short starter instruction so it creates the shell without wasting credits. Paste this exactly:

Create a new full-stack web app for a global child-safe digital creation, learning and achievement platform for under-16s, with a separate 16+ alumni environment.

For now, only create the basic application shell: responsive layout, authentication placeholders, top-level navigation, and empty dashboard routes for Child, Parent, Teacher, School Admin, Education Group Admin and Alumni.

Do not build detailed features, database tables, AI functionality, payments, moderation workflows or complex design yet. Keep the UI clean, premium and neutral. We will build most functionality through GitHub and Supabase.

Use React, TypeScript, Tailwind and shadcn/ui. Structure the code cleanly for future GitHub development.

This project was built with [Lovable](https://lovable.dev).
